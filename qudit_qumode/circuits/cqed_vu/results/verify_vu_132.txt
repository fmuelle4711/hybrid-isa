================================================================================================
ANSWER
================================================================================================
  132 is not a number we assigned.  Vu's own published script emits
  148 instructions per second-order Trotter step, of which 16
  are barriers -- transpiler scheduling directives that compile to
  nothing and occupy no pulse slot.  148 - 16 = 132.

  Every primitive type matches our re-implementation exactly, so the
  JSON, the HybridLane port, and Vu's own code all agree.

  What 132 is NOT: it is not Vu's paper's count.  Their stated '96
  gates per step' is an abstract operator decomposition, hardcoded
  at simulations/circuit_diagrams.py:545 as a citation.  We have
  never recounted 96 and this script does not check it.
